# Saxam Anand - Portfolio Website

## Overview
This is a personal portfolio website for Saxam Anand, a Computer Science Engineering graduate. The website showcases his education, skills, projects, and provides contact information.

## Features
- Responsive design that works on all devices
- Interactive navigation menu
- Sections for About, Skills, Projects, Education, and Contact
- Downloadable PDF resume
- GitHub and LinkedIn integration
- Contact form

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome for icons
- Google Fonts
- html2pdf.js for PDF generation

## Sections
1. **Home** - Introduction and quick links
2. **About** - Personal information and background
3. **Skills** - Technical skills and competencies
4. **Projects** - Showcase of completed projects
5. **Education** - Academic background
6. **Contact** - Contact information and form

## Projects Featured
1. **Image Watermarking Tool** - A Java application using Swing and AWT
2. **Phishing URL Detector** - A machine learning web application built with Streamlit

## How to Use
1. Clone the repository
2. Open `index.html` in your browser
3. Navigate through the sections using the menu
4. Download the resume by clicking the "Download Resume" button
5. Use the contact form to send a message
